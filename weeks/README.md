# Weeks

One file per week, copied from `checkin-template.md`:

```
week-01.md … week-12.md
```

Each file is the check-in plus, or a link to, the week's artefact (a model, a SQL
file, a write-up, the capstone). Keep the artefact in the repository — a path
outside it is a promise, not a record.

The ledger at the repository root is the source of truth for whether the week
happened. These files are the detail.
